# @senvenli/react

Web components built on React Aria Components and Tailwind v4, themed by [`@senvenli/tokens`](../tokens).

Status: planned. Components are being extracted from an existing production library (about 105 components in 13 families: action, form, selection, collection, display, feedback, navigation, overlay, date, color, layout, charts). Component names and props match [`@senvenli/react-native`](../react-native).
