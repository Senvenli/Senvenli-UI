# @senvenli/mcp

An MCP server that lets AI coding agents (Claude Code, Cursor, and others) build with Senvenli UI.

Planned tools:

- `list_components`
- `search_components`
- `get_component_docs`: props, anatomy, examples, accessibility notes
- `get_docs`
- `get_install_command`
- `get_theme_tokens`
- `generate_theme`: preset inputs or code → CSS, native hex theme, preset code, builder URL and a contrast report (same engine as the builder page and the CLI)
- `validate_theme`: contrast audit of an existing theme

Status: planned.
