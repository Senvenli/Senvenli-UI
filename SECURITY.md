# Security

Please report security issues privately: open a [private vulnerability report](https://github.com/Senvenli/Senvenli-UI/security/advisories/new)
on this repository instead of a public issue. Include the package and version, what you found and how to reproduce it.

We acknowledge reports within a few working days. Fixes ship in a patch release of the affected packages
(`@senvenli/react`, `@senvenli/tokens`, `@senvenli/cli`, `@senvenli/mcp`), with credit if you want it.

The hosted MCP endpoint at `https://design.senvenli.com/mcp` serves public, read-only documentation; reports about it
are welcome through the same channel.
